Import dans Unity

Lat-long en cubemap — sélectionner la texture, Texture Shape → Cube, Mapping → Latitude-Longitude Layout (Cylindrical), cocher Convolution Type: None pour un skybox, Specular pour une réflexion.

Bande ou croix en cubemap — Texture Shape → Cube, Mapping → 6 Frames Layout (Cubic Environment). L'ordre de la bande est +X −X +Y −Y +Z −Z, celui attendu par Unity.

6 faces séparées — matériau Skybox/6 Sided : _RightTex=posx, _LeftTex=negx, _UpTex=posy, _DownTex=negy, _FrontTex=posz, _BackTex=negz. Mettre Wrap Mode: Clamp sur les six, sinon des lignes apparaissent aux arêtes.

Fichiers .hdr — Unity les importe nativement. Activer High Dynamic Range dans l'importateur et laisser la compression sur BC6H pour une lightmap ou une réflexion.

Éclairage — Window → Rendering → Lighting → Environment → Skybox Material, puis Generate Lighting pour que l'ambiante suive la nouvelle sphère.
